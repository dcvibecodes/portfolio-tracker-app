Display & Currency

Configure date format, base currency, and exchange rate display.

  • Base currency: all portfolio values (invested, current value, P&L) are shown in this currency.
  • Foreign currency transactions: when adding a holding in a different currency, you'll be asked for the actual base-currency amount you spent. This ensures your "Invested" figures reflect real outflows.
  • Exchange rate display: optionally show a live exchange rate on the dashboard (e.g. USD/INR).
